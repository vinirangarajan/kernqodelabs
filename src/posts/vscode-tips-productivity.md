## 1. Multi-Cursor Editing

Hold `Alt` and click to place multiple cursors. Edit multiple lines at once — this alone saves hours.

```
Alt + Click       → Add cursor
Ctrl + Alt + ↑/↓  → Add cursor above/below
Ctrl + D          → Select next occurrence
```

## 2. Command Palette is Everything

`Ctrl + Shift + P` opens everything. You can rename files, change language mode, run tasks — without touching the mouse.

## 3. Zen Mode

`Ctrl + K Z` hides everything except your code. Zero distractions. Pure focus.

## 4. Live Share for Pair Programming

Install the **Live Share** extension and collaborate in real-time with your team. It's like Google Docs, but for code.

## 5. Git Lens

**GitLens** shows who wrote every line of code and when, right inside the editor. Invaluable for team projects.

## Bonus: Snippets

Create your own code snippets with `File → Preferences → User Snippets`. We have snippets for React components, API calls, and more.
